Limits of this report

  • One tool runs at a time. Each tool's path is checked with its own blast gate open. Two tools running together are not in this report.
  • Fan curves marked derated are planning curves for a class of collector, not a test of your tool. Results are only as good as the curve used.
  • Fitting losses are standard planning values in equivalent feet of pipe, not lab tests of your fittings.
  • Check the parts list against the drawing before you buy. Add spares for couplings, tape, hangers, and fasteners.
