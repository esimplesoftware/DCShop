How to read a line
  CFM   how much air the machine asks for.
  FPM   how fast that air moves. Fast enough to carry chips, not so fast it wastes suction.
  SP    static pressure, in inches of water. Higher means the collector has to work harder.
  eq-ft equivalent feet. A bend or flex is counted as if it were extra straight pipe.
  Fixed losses   cyclone plus filter. Added on every run. Not the pipe.

Whole design
  6 machines, 6 branches drawn, 6 blast gates.
  Each block above is that machine alone. Two open gates at once are not checked.
  Hardest machine in this pass: Floor sweep, asking the collector for 14.36" SP.
  None of the published collector curves covers this hardest run. Lower the pipe load before comparing a larger unit.
  Design check: the main and branch sizes now match the recommendations. No size change is recommended.
  Limits
  Vendor curves: a free-air CFM number, or a curve taken with no filter and a short straight duct, can look stronger than the same unit in a shop. If the sheet does not say the test includes the separator and filter, enter the curve and then add those losses, or drop the CFM at each point before you trust a close call.
  Fitting equivalent feet are planning numbers from the pipe-spec table, not a lab test of your fittings.
  Only one open gate is checked. Two machines running together are not in this report.
  Built-in classes marked derated are planning curves, not a measured test of a named machine.

Planning aid using published small-shop tables. Not an engineered design. A vendor free-air CFM number is not a fan curve. Verify the test conditions with the collector manufacturer. Follow local fire and electrical codes.
