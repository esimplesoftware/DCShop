How it works

Most layouts are guessed from a chart. DCShop makes the layout visible and checks it before the pipe is bought.

01

Draw what you can build

Room, collector, main in 90° and 45° sticks, one branch per machine with a gate and flex. Illegal fittings are refused.

02

Colors are only velocity

Green, yellow, and red answer whether chips will stay in the airstream. They do not grade the collector.

03

The report grades the collector

CFM, FPM, static pressure, equivalent feet, plus fixed cyclone and filter losses, compared to a collector class.

On the floor

What it does and does not do

1.0 plans one open machine at a time from the pipe you drew. That is the whole product.

Does

  • Use the drawn length, elbows, and flex
  • Keep transport velocity and collector capacity separate
  • Show derated planning curves and a published manufacturer curve as different things
  • Refuse a change that cannot be built
  • Export a full-floor page that zoom does not clip

Does not

  • Invent lengths you did not draw
  • Treat green as “this collector is enough”
  • Stamp an engineered or NFPA design
  • Analyze every blast gate open at once
  • Upload your shop file (it stays on your PC)

Questions

Short answers. The limits are intentional.

Is this a replacement for a manufacturer’s design service?

No. A dealer design is a parts list tied to a purchase. DCShop is the drawing you run before you order pipe from anyone. Use both if you want.

Why are the length boxes read-only?

Because the analysis uses the pipe on the floor. If the number could be typed, the drawing would stop being the calculation.

Can I run two machines at once?

1.0 analyzes one open machine. That is how most one-person shops actually run blast gates.

Is a planning curve the same as a published fan curve?

No. DCShop will not present a derated planning curve as if it were a manufacturer’s published curve.
