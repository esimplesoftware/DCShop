DCShop

Draw the shop. Check whether the pipe can carry chips, and whether the collector can pull that air.

DCShop is a Windows desktop planner for a small woodshop dust-collection system. You draw the room, the collector, the main, and one branch per machine. Analysis uses the pipe on the floor — it does not invent lengths.

Status: 1.0.0 — paid Windows app. A license is required.

What it does





Draw the room, place a collector, and lay the main in 90° and 45° sticks.



Place machines from a catalog and connect each with a branch, a blast gate, and flex.



Slide wyes, move machine names, and keep fittings on legal sticks. A change that cannot be built is refused, and the status line says why.



Run an analysis for one machine at a time using the drawn pipe, elbows, and flex.



Compare the run with a collector class. Derated planning curves and a manufacturer’s published curve are labeled as different things.



Recommend main and branch sizes, apply those sizes, and run again.



Save the shop, reopen it, and export a printable page of the floor plus the analysis.

Green, yellow, and red answer only whether air is fast enough to carry chips. The report answers whether this collector can pull that air through this pipe.

A layout picture is on the product page. A full analysis is the sample report.
